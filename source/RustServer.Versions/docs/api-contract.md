### `OxideVersionInfo`

| Field | Type | Required | Nullable | Description |
| --- | --- | --- | --- | --- |
| `availableVersion` | `string` | Yes | No | Latest Oxide version available from GitHub. |
| `installedVersion` | `string` | No | Yes | Oxide version installed on disk, or null when Oxide is not installed. |
